# Frozen Fridge

Responsive online store for frozen food products.

**Live demo:** https://ahmednabil2002.github.io/frozen-fridge/

## Tech Stack

- React 19
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
